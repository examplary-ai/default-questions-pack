The picture choice question type is multiple choice with images instead of text: students look at a set of pictures and select the one that answers the question. When the content is inherently visual, this beats describing images in words.

## When to use it

- Visual recognition: identifying shapes, organisms, artworks, diagrams, or symbols.
- Geography and biology questions built on maps, specimens, or figures.
- Early-years or language-light assessment where reading load should stay minimal.

## How it works for students

The images are displayed as a grid of selectable cards, and the student clicks the one they believe is correct. Answering takes about 2 minutes.

## Grading

Scored automatically: the selected image is compared against the configured correct answer.

## Settings

| Setting        | Description                             |
| -------------- | --------------------------------------- |
| Options        | The images to choose from.              |
| Correct answer | Which of the images is the correct one. |
