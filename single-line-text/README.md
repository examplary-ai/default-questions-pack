The single-line text question type asks for a short, free-form answer in one line: a word, a name, a number, a term. It sits between multiple choice and open questions — students must produce the answer themselves, but grading stays quick.

## When to use it

- Short recall without answer options: "What is the chemical symbol for gold?"
- Terminology, names, translations, short calculations.
- Anywhere multiple choice would give the answer away by showing it as an option.

## How it works for students

The student types their answer into a single-line input field, optionally limited to a maximum length. Answering takes a minute or two. (Tip: this type has keyboard shortcut `1` in the editor.)

## Grading

Graded by AI against your scoring criteria, with your review. Because answers are short, grading suggestions are usually very reliable — spelling variations and synonyms are judged in context rather than by exact match.

## Settings

| Setting    | Description                                           |
| ---------- | ----------------------------------------------------- |
| Max length | Optional maximum number of characters for the answer. |
