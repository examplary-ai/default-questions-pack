The true / false question type presents a statement, and the student decides whether it is true or false. It's the quickest question format there is — ideal for rapid checks, but best used deliberately: with only two options, a blind guess is right half the time.

## When to use it

- Quick checks of common misconceptions: "The Great Wall of China is visible from space."
- Warm-up questions at the start of a test or topic.
- Larger banks of short questions where speed matters more than depth.

Consider pairing true/false questions with a follow-up open question ("explain why") when you want to rule out lucky guesses.

## How it works for students

The statement is shown with True and False buttons; the student picks one. Answering takes well under a minute.

## Grading

Scored automatically against the configured correct answer. Given the 50% guess rate, a single point per question is the sensible choice.

## Settings

| Setting        | Description                                 |
| -------------- | ------------------------------------------- |
| Correct answer | Whether the statement is `true` or `false`. |
