The classic multiple choice question: one correct answer among several options. Fast to answer, instantly scored, and reliable — the backbone of most knowledge checks.

## When to use it

- Factual recall with one right answer: "What is the capital of Australia?"
- Concept checks with well-chosen distractors that reveal common misconceptions.
- Larger tests where automatic scoring keeps grading time manageable.

Good distractors make or break this question type: each wrong option should be plausible to a student with a specific misunderstanding.

## How it works for students

The options are shown as a radio list and the student picks exactly one. Answer options can contain mathematical notation, which is displayed properly to the student. Answering takes about a minute. (Tip: this type has keyboard shortcut `3` in the editor.)

## Grading

Scored automatically: the selected option is compared against the configured correct answer. A single point per question is the usual choice.

## Settings

| Setting        | Description                                                     |
| -------------- | --------------------------------------------------------------- |
| Options        | The list of answer options. Make sure all options are distinct. |
| Correct answer | Which of the options is the correct one.                        |
