The matching question type presents two lists, and the student connects each item on the left with its counterpart on the right. It's a compact way to test associations: term ↔ definition, country ↔ capital, artist ↔ work.

## When to use it

- Pairing terms with definitions, causes with effects, or examples with categories.
- Testing several related facts in a single question instead of a series of small ones.
- Quick automatically-scored checks of associative knowledge.

Keep the lists short — two to five pairs works best. Longer lists make the question tedious rather than harder.

## How it works for students

The student sees both lists and connects each left item to a right item. On printed sheets, both lists are shown in the configured order, so make sure the right-hand list is _not_ in the same order as its matches on the left — otherwise the answer gives itself away. Answering takes about 2 minutes.

## Grading

Scored automatically: the student's set of pairs is compared against the configured correct pairs.

## Settings

| Setting | Description                                           |
| ------- | ----------------------------------------------------- |
| Items   | The items in the left-hand and right-hand lists.      |
| Layout  | Vertical or horizontal presentation of the two lists. |
| Shuffle | Whether to shuffle the items shown to the student.    |
