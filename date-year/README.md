The date / year question type asks the student for a specific point in time — either a year (e.g. 1789) or a full calendar date (e.g. 31 December 1925). The input field enforces the right format automatically, so students can't answer in prose and you never need to decipher ambiguous date notations.

## When to use it

- History questions with a single, unambiguous answer: "In which year did the French Revolution begin?"
- Any factual question where the answer is a date: publication years, birth dates, treaty dates.
- Quick knowledge checks where you want automatic scoring.

## How it works for students

The student sees a dedicated year or date input, matching the format you selected. There is no free-text interpretation involved: the answer is either the configured year/date or it isn't. Answering typically takes a minute or two.

## Grading

Scored automatically: the student's input is compared against the configured correct answer. No manual review is needed.

## Settings

| Setting | Description |
| --- | --- |
| Date type | Whether the student should enter just a year or a full date. |
| Correct answer | The correct year (e.g. 1789) or full date, matching the chosen date type. |
