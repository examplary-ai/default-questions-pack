The sequence question type asks students to arrange a set of items into the correct order by dragging them into place. It tests ordering knowledge directly: chronology, process steps, rankings, and procedures.

## When to use it

- Chronology: ordering historical events, life cycle stages, plot points.
- Processes and procedures: steps of an experiment, an algorithm, a recipe.
- Rankings: smallest to largest, first to last, cause to effect.

Five or fewer items keeps the question sharp; with more items, a single slip cascades into many "wrong" positions.

## How it works for students

The items appear in a random order, and the student drags them into the sequence they believe is correct. Answering takes about 2 minutes.

## Grading

Scored automatically: the question is correct only when _every_ item is in the right position. Because of this all-or-nothing scoring, a small point value (typically 1 point) is recommended.
