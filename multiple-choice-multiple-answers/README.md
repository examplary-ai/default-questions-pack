This question type shows a list of options of which _more than one_ can be correct, and students select all that apply. It's stricter than it looks: to earn the point, students must select exactly the right set — every correct option and no incorrect ones.

## When to use it

- "Select all that apply" questions: properties, examples, members of a category.
- Testing whether students can discriminate between similar-looking options.
- Automatically-scored checks that are a step harder than single-answer multiple choice.

## How it works for students

The options are shown as checkboxes and students tick every answer they believe is correct. It's worth telling students explicitly that multiple answers may be correct. Answer options can contain mathematical notation, which is displayed properly to the student. Answering takes about a minute.

## Grading

Scored automatically: the selected set is compared against the configured correct answers. Because an answer is either exactly right or not, a small point value (typically 1 point) is recommended.

## Settings

| Setting        | Description                                                     |
| -------------- | --------------------------------------------------------------- |
| Options        | The list of answer options. Make sure all options are distinct. |
| Correct answer | Which of the options are the correct ones.                      |
