The file upload question type lets students hand in a file as their answer: a document, spreadsheet, image, piece of code, or any other artefact. It turns a test question into a small assignment hand-in, with the submission attached to the question for grading.

## When to use it

- Handing in work created outside the test: reports, lab write-ups, designs, code.
- Photographed handwritten work, such as worked calculations or sketches.
- Practical assignments where the product itself is what you assess.

## How it works for students

The student uploads their file through a file picker or drag-and-drop. You can restrict which file types are accepted (e.g. PDF only) to avoid format surprises when grading. Since students typically produce the artefact during the test, the time estimate is around 20 minutes.

## Grading

Graded by AI where possible — the uploaded file is opened and assessed against your scoring criteria — with your review. For file formats the AI can't inspect, you grade manually as usual.

## Settings

| Setting             | Description                                               |
| ------------------- | --------------------------------------------------------- |
| Accepted file types | Which file types students may upload (default: any file). |
