The multi-line text question type asks for an open answer of a few sentences to a few paragraphs, in a plain multi-line text box. It's the workhorse for "explain", "describe", and "compare" questions where you want the student's own words without the overhead of a full essay.

## When to use it

- Short explanations: "Describe the main stages of the water cycle."
- Definitions in the student's own words, short arguments, worked reasoning in prose.
- Anything too long for a single line but not structured enough to need headings.

If students should format their answer with headings and rich text, use the essay question type instead.

## How it works for students

The student types their answer into a multi-line text area. There are no formatting tools — just text. A typical question takes around 5 minutes. (Tip: this type has keyboard shortcut `2` in the editor.)

## Grading

Graded by AI against your scoring criteria, with your review. Specific criteria ("names all three stages", "mentions condensation") produce more consistent suggestions than one broad criterion.
