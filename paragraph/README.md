The paragraph block inserts a page of content into the test without asking for an answer. Use it to give students context they'll need for the questions that follow: a source text, a data table, a graph, an image, or instructions for a new section.

## When to use it

- Introducing a new section of the test ("The next five questions are about the text below").
- Providing source material: articles, case descriptions, datasets, diagrams, links.
- Splitting a long test into readable parts with context at the right moments.

Don't use a paragraph for the welcome or closing text of the test — the dedicated introduction and outro blocks handle those (and always appear in the right position).

## How it works for students

The content is shown as a full page between questions. Students read it and move on; there is nothing to answer.
