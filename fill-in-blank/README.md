The fill-in-the-blank question type (also known as a *cloze* question) shows the student a sentence or short passage with one or more gaps to complete. It tests precise recall in context: the surrounding text gives the frame, and the student supplies the missing terms.

## When to use it

- Vocabulary and terminology: "The powerhouse of the cell is the ___."
- Facts embedded in context: names, places, dates, formula components.
- Language learning: verb conjugations, prepositions, spelling.

## How it works for students

The passage is displayed with an input field at every blank. Students type a short answer into each gap. A typical fill-in-the-blank question takes about 2 minutes.

## Grading

Scored automatically: each blank is compared against the corresponding entry in the configured correct answers. Because the question is either right or wrong per blank, it works best with a small point value (typically 1 point).

## Settings

| Setting | Description |
| --- | --- |
| Text | The passage containing one or more blanks, written as `___` (three underscores). |
| Correct answers | One correct answer per blank, in the same order as the blanks appear in the text. |
