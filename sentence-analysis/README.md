The sentence analysis question type is built for Dutch grammar teaching (_redekundig ontleden_): students split a sentence into its sentence parts (_zinsdelen_), assign the correct grammatical label to each part, and optionally mark the finite verb (_persoonsvorm_).

## When to use it

- Practising and testing redekundig ontleden in Dutch language classes.
- Focused drills on specific sentence parts by limiting which labels are enabled.
- Both formative practice and graded tests — the type scores automatically.

Prefer single-clause sentences with a clear structure; they keep the exercise unambiguous.

## How it works for students

The sentence is shown word by word. Students select contiguous groups of words to form sentence parts, pick a label for each part from the enabled set (e.g. OW, WG, LV, BWB), and — if required — mark the persoonsvorm. Every word must end up in exactly one sentence part. Plan for roughly 4 minutes per sentence.

## Grading

Scored automatically against the configured correct segmentation, labels, and persoonsvorm. AI grading is also enabled for reviewing nuanced cases.

## Settings

| Setting              | Description                                                                                    |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| Sentence             | The sentence to analyse.                                                                       |
| Enabled labels       | Which labels students can use (e.g. OW, WG, LV, BWB).                                          |
| Require persoonsvorm | Whether students must also mark the finite verb (default on).                                  |
| Correct answer       | The correct division of the sentence into labelled sentence parts, including the persoonsvorm. |
